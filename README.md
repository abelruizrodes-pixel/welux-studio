# WELUX STUDIO // Luxury Digital Growth, Creative Lab & Cinema Rentals

> **Luxembourg • Madrid • Paris**  
> Plataforma digital oficial de **Welux Studio** y división técnica **Amcropa Films**.  
> Especialistas en Social Media Growth, Producción Cinematográfica 4K, Diseño Web High-End, Tours Virtuales Inmersivos 360° con LiDAR y Alquiler de Material Técnico de Cine.

---

## 🏛️ Descripción del Proyecto

**Welux Studio** es una plataforma web moderna tipo Single Page Application (SPA) ultra-optimizada, diseñada bajo los principios del *Quiet Luxury* y la excelencia visual europea.

Incluye 6 universos creativos, demostraciones interactivas en vivo, catálogo de material cinematográfico profesional y calculadoras de presupuestos en tiempo real.

## ✨ Características Principales

### 1. 🔄 Arquitectura SPA Fluida & Navegación Sin Recargas
- Enrutamiento por JavaScript modular (`navigateTo(pageId)`).
- Transiciones suaves y partículas ambientales interactivas en canvas dorado.
- Tipografía refinada: *Playfair Display*, *Cinzel*, *Plus Jakarta Sans* y *JetBrains Mono*.

### 2. 🌌 Los 6 Universos Creativos & Técnicos
- **01 // Social Media Growth & Viralidad**: Estrategia de crecimiento orgánico y guionización de alto impacto en 𝕏, Instagram Reels, TikTok y YouTube Shorts.
- **02 // Creación de Contenido & Dirección de Arte**: Producción 4K de autor, estilismo y dirección artística presencial para eventos y marcas exclusivas.
- **03 // Diseño & Desarrollo Web Boutique**: Arquitectura web ultra-rápida (< 1.4s) enfocada en captar clientes de alto valor.
- **04 // Marketing, Performance Ads & Fúneles**: Estrategia de paid media con un ROAS promedio de 4.9X.
- **05 // Alquiler de Material Técnico & Fotomatón Glam (Amcropa Films)**:
  - Cámara de Cine *Blackmagic URSA Mini Pro 4.6K G2* + Óptica de cine *Sigma 18-35mm T2 Highspeed Zoom*.
  - Monitoreo táctil *Blackmagic Video Assist 7"*.
  - Estabilización por chaleco y brazo de doble muelle *Flycam Galaxy* + *Redking* + trípode de cabeza fluida *Cam Gear TA-2*.
  - Grabación de sonido de campo a 32-bit float con *Zoom F6* + microfonía cañón *Røde NTG-2* + paravientos *Blimp MKII*.
  - Cabinas de *Fotomatón Glam HD* con beauty filter e impresión térmica instantánea + escenografías instagrameables a medida.
- **06 // Tours Virtuales 360°, Gemelos Digitales 3D & LiDAR Pro**:
  - Digitalización espacial para **Inmobiliarias de Lujo**, **Sedes Corporativas de Oficinas**, **Hoteles Boutique & Resorts** y proyectos de **Arquitectura & Reformas**.
  - **Simulador Interactivo 360°**: Conmutador de 3 espacios (Penthouse de 380m², Sede de Oficinas de 1.200m², Hotel 5★ de 2.400m²).
  - **3 Modos de Vista**: Recorrido 360° con puntos interactivos (Mattertags de calidades), vista *Dollhouse 3D* axonométrica y *Plano 2D acotado con medidas láser*.
  - **Auto-rotación 360°** y modo Realidad Virtual (VR) compatible con Apple Vision Pro y Meta Quest.

### 3. 🧮 Herramientas Interactivas & Calculadoras
- **Calculadora de Presupuestos de Alquiler Audiovisual**: Selección por packs de equipamiento y días con descuentos progresivos por duración.
- **Calculadora de Tours Virtuales 360°**: Cálculo en tiempo real según tipo de inmueble, superficie en m² y extras (planos 2D, Mattertags, vídeo teaser 4K, vuelo de dron FPV).
- **Simulador de Retorno de Inversión (ROI & ROAS)**: Proyección de alcance e impacto según presupuesto mensual publicitario.
- **Emulador de Dispositivos (Device Tester)**: Previsualización responsiva en tiempo real en formato Desktop, Tablet y Mobile.

## 🚀 Despliegue en GitHub Pages

1. **Crear repositorio en GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Welux Studio official app with 360 Virtual Tours"
   git branch -M main
   git remote add origin https://github.com/TU-USUARIO/welux-studio.git
   git push -u origin main
   ```

2. **Activar GitHub Pages**:
   - Entra en tu repositorio en GitHub > **Settings** > **Pages**.
   - En **Source**, selecciona `Deploy from a branch`.
   - Selecciona la rama `main` y la carpeta `/ (root)`.
   - Haz clic en **Save**. En 1 minuto tendrás tu web online con HTTPS gratuito.

### Qué es este repo

- Fuente de **weluxhub.com**, publicada con **GitHub Pages** desde la rama `main`.
- Sitio multi-página por idioma: el español vive en la raíz (`index.html`, `gear/`, `films/`, `studio/`, `careers/`) y las demás lenguas en sus carpetas: `en/`, `fr/`, `de/`, `pt/` y `lu/`.
- Secciones principales: **Gear** (alquiler de material de cine), **Films**, **Studio** y **Careers**.
- Script central: `assets/js/welux-v2.js` (efectos, parallax, vídeo del hero y botón de cambio de idioma). Las páginas comparten la misma base de estilos con Tailwind.

### ⛔ REGLA DURA — Tema claro (no es un error)

- `assets/js/welux-v2.js`, línea 17: `document.documentElement.classList.remove('dark')` quita el modo oscuro al cargar la página. El tema claro es deliberado.
- Las plantillas declaran `<html class="dark">` y Tailwind está configurado con `darkMode: "class"`. Esa combinación es intencional: el tema claro se fuerza por script al cargar.
- **No quitar ni «arreglar» esa línea ni el `class="dark"` del `<html>`.** Quien la lea como un error está equivocado: es el comportamiento querido del sitio.

### ⛔ REGLA DURA — Datos personales (nunca en el código público)

- Nunca publicar en este repo público: dirección particular, teléfono, WhatsApp, RCS ni pólizas.
- Único contacto público: **info@weluxhub.com**.
- El RCS solo va detrás de la puerta de datos del aviso legal; nunca en el código público.

### Sin paso de compilación

- Tailwind se carga por **Play CDN** (`cdn.tailwindcss.com`); no hay `package.json` ni `tailwind.config.js` (la configuración de Tailwind vive en línea en cada página).
- Las páginas parecen generadas por scripts (`generate_multilingual_complete.py`, `build_full_multilingual_ecosystem.py` en la raíz): **no regenerar**. Regenerar reintroduce la dirección, el teléfono y el WhatsApp que ya se quitaron a mano.
- Los cambios se hacen editando directamente los archivos HTML en `main`.

### Backend

- **Worker `weluxhub-api`** + base de datos **D1 `welux-leads`** (ver carpeta `worker/`).
- Los formularios guardan los envíos en D1.
- Notificaciones por correo con **Resend** (secreto `RESEND_API_KEY`, nunca en el repo) o **MailChannels** como respaldo.

### Despliegue

- **GitHub Pages**: cada push a `main` lanza un despliegue nuevo y cancela el despliegue anterior.
- Durante la propagación, el CDN puede mezclar versiones viejas y nuevas: **verificar en vivo solo al final**, cuando el despliegue de ese push haya terminado.
