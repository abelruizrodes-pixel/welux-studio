// PREGUNTAS FRECUENTES

Dudas Comunes sobre Tours Virtuales 360°

¿Cuánto tiempo lleva escanear una propiedad?

Para un piso de 100-150 m², la captura con LiDAR toma entre 1 y 2 horas. En sedes de oficinas de más de 1.000 m² se realiza en 3-5 horas, habitualmente fuera de horario laboral para no interrumpir la actividad.

¿Cómo se publica en portales inmobiliarios?

Te entregamos un enlace directo compatible con Idealista, Fotocasa, Athome.lu, JamesEdition y portales internacionales, además de un código iframe de una línea para incrustar en tu propia web.

¿Qué precisión tienen los planos 2D generados?

Gracias a los sensores LiDAR de infrarrojos, el margen de error es inferior al 1%, siendo aptos para tasaciones, memorias de venta, proyectos de interiorismo y reformas.

¿Es necesario instalar alguna aplicación para verlo?

No. La experiencia funciona 100% en el navegador web de cualquier teléfono móvil, tablet u ordenador, además de ser compatible con gafas de Realidad Virtual como Apple Vision Pro o Meta Quest.
